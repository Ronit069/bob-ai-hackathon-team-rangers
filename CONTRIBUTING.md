# Contributing

**Template file — do not delete.** This is a Phase 1A placeholder.

When the repository is created from the official template (`bob-ai-hackathon-submission-template`), replace this file with the template's `CONTRIBUTING.md` unchanged.

Working rules for this team (summary — full version in `docs/phase-0/team-ownership.md`):

- One shared repo; `main` is always demoable.
- Feature branches: `feat/<area>-<task>`; every merge via PR reviewed by the other member.
- No direct pushes to `main`.
- Daily sync: done / next / blockers. Blocked > 30–45 minutes → switch to a backup task and record the blocker.
- Definition of Done applies to every task (`docs/phase-0/phase-plan.md` §5).
- Never commit `.env`, credentials, `node_modules/`, `__pycache__/`, `.venv/` or build artefacts.
