# backend/ — ChainSentinel REST API

Node.js 20 + Express 4 (ESM), `zod` validation, `pg` driver, **no ORM**.

## Modules (ownership)

| Folder | Owner | Scope |
|---|---|---|
| `src/common/` | Shared | config/env, pg pool, zod schemas, error envelope, logging |
| `src/logistics/` | M1 | disruptions, shipments, routes, carriers, fleet, alternatives, redeployment |
| `src/coldchain/` | M2 | readings, quality, excursions, severity, policies, alerts |
| `src/risk/` | Shared | combined score, snapshots, overview |
| `src/audit/` | Shared | append-only audit, decisions |
| `src/bob/` | M2 | optional `/api/bob/query` proxy |

## Scripts

- `npm run dev` — start with watch mode
- `npm run migrate` — apply numbered SQL migrations
- `npm run seed` — load validated fixtures (transactional)
- `npm run validate` — referential integrity + scenario coverage + ground truth
- `npm test` — `node:test`

## Status

All 28 REST endpoints are implemented (Phase 3) on top of the Phase 2 PostgreSQL 16 (Docker) schema, deterministic services and zod validation. Seed fixtures are generated by `src/data-generator` (Python) and loaded with `npm run seed`. Unknown `/api/*` paths return a standard `404` envelope. Contracts: `docs/phase-0/api-contract.md`, `docs/phase-0/data-contract.md`.

## Scripts

| Command | Purpose |
|---|---|
| `npm run dev` / `npm start` | start the API on `:3001` |
| `npm run migrate` | apply numbered SQL migrations |
| `npm run seed` | load `data/seed/*.json` transactionally (truncates by default; `--keep` to append) |
| `npm run validate` | fast pre-seed referential check (full validation: `src/data-generator/validate.py`) |
| `node scripts/verify-seed.js` | compare JS services against the Python ground truth |
| `node scripts/simulate-feed.js` | demo freshness: post current in-policy readings for one cold shipment (fixtures untouched) |
| `npm test` | backend test suite (`node:test`) |
